# Editing the TokTokMart UI

Open the **TokTokMart** scene with Play Mode stopped. Choose **TokTokMart → UI → Open UI Layout Editor** and select a preview.

- **Menu, HUD, tasks, and settings** live in the scene. Expand **TokTokMart UI** or **Restock UI** in the Hierarchy. Select a group and use the Rect tool (**T**) or the Inspector. Move a whole button group to keep its artwork and hit area together.
- **Choose a Shift, Shift Results, and Shift Transition** open the punch-card prefab in Prefab Mode. Save the prefab with **Ctrl+S**, then choose **Return to Scene Canvas** to edit the other screens.
- **Canvas Binding** connects scene UI to the game. Keep **Bind Game Data** enabled for live values and **Animate Layout** enabled for progress bars and controls. Turn off **Bind Game Data** for fixed text or artwork. **Hide From Game** hides an element or group in previews and gameplay.

Use the **Scene** tab to edit and the **Game** tab to inspect the result. Save the scene with **Ctrl+S** before testing in Play Mode.
